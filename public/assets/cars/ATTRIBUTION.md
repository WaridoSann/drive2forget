The user supplied the original USDZ model. The included model, delivered through `model.json` and its `m5-f90.glb.gz.001` / `m5-f90.glb.gz.002` parts, is a content-preserving technical conversion for browser use under licence section 2(a)(4): USDZ to glTF 2.0, centimetre-to-metre unit transform, texture-coordinate convention conversion, packing of the original metallic/roughness channels without resizing, exact-buffer deduplication and lossless gzip compression. Original geometry, normals, mesh transforms and PBR values are retained. No decimation, recolouring, artistic material edits or mesh splitting was performed. The four wheels reuse separate nodes already present in the original model.

The two static parts contain 7,000,000 and 6,001,607 bytes. Concatenating them in manifest order recreates the exact 13,001,607-byte gzip; its decoded GLB contains 16,443,596 bytes. Splitting the transport does not change the model, and the loader verifies the combined gzip SHA-256 before decompression. No combined `m5-f90.glb.gz` file is shipped.

The converted model contains **56 meshes, 917,348 triangles, 33 materials and 11 embedded images**. See [CONVERSION_MANIFEST.json](CONVERSION_MANIFEST.json) for the per-mesh provenance and checksums.
